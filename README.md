# PyTorch Fundamentals

This notebook covers the fundamentals of **PyTorch** and introduces the basic concepts required for Deep Learning.

## Topics Covered

* Creating and understanding **PyTorch tensors**
* Tensor shapes, dimensions, datatypes and devices
* Random, zero and one tensors
* Tensor arithmetic and **matrix multiplication**
* Reshaping, stacking, squeezing, unsqueezing and permuting
* Tensor indexing
* Aggregation functions: `min`, `max`, `mean`, `sum`, `argmin`, `argmax`
* Converting between **PyTorch tensors and NumPy arrays**
* Reproducibility using random seeds
* Using **GPU (CUDA)** with PyTorch
* Moving tensors between CPU and GPU

## Libraries Used

* Python
* PyTorch
* NumPy
* Pandas
* Matplotlib
